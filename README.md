# ZuhauseBleiben Kompass

Unabhängiger Ratgeber für ältere Menschen und ihre Angehörigen: Treppenlift, barrierefreier Badumbau, Hausnotruf und altersgerechtes Wohnen — mit quellenbelegten Förderzahlen (§ 40 SGB XI, KfW), Druck-Checklisten und Angebotvergleichen.

**Website:** https://zuhausebleiben-kompass.de

- 26 Ratgeber, alle Zahlen gegen Originalquellen (gesetze-im-internet.de, kfw.de, BMG) verifiziert
- KfW-455-B Status-Tracker (Gist): https://gist.github.com/banana-orama/e74e67051c092b71a96eff56d4385c29
- Druckbare Checklisten: https://zuhausebleiben-kompass.de/checklisten/
